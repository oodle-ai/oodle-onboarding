Download APK
  1. Connect your phone and computer to the same Wi-Fi.
  2. Tap Download APK. Open the downloaded file.
  3. If prompted, allow installation from this browser. Return and tap Install.

Keep the demo API running on your computer while you use the app.

This APK is for Android. For iPhone, use the local Xcode installation steps in the repository.
